a) Como a imagem mudou após cada filtro?
Média: deixou a imagem mais suave, porém perdeu detalhes.
Mediana: reduziu ruídos mantendo melhor as bordas.
Sobel: destacou as bordas e contornos dos objetos.



b) Qual filtro foi mais eficaz para suavizar?
O filtro de mediana apresentou melhor resultado na remoção de ruídos sem borrar excessivamente a imagem.



c) Qual filtro destacou melhor as bordas?
O filtro Sobel foi o mais eficiente para evidenciar contornos e detalhes.


d) Aplicações em projetos reais
| Filtro  | Aplicações                               |
| ------- | ---------------------------------------- |
| Média   | Suavização simples                       |
| Mediana | Remoção de ruídos em imagens digitais    |
| Sobel   | Detecção de bordas e visão computacional |
