a) Como a imagem original mudou após a aplicação de cada filtro?

Filtro de Média: deixou a imagem mais suave, porém um pouco borrada.
Filtro de Mediana: reduziu ruídos mantendo melhor os detalhes.
Filtro Sobel: destacou as bordas e contornos da imagem.




b) Qual filtro foi mais eficaz para suavizar a imagem?

O filtro de mediana foi o mais eficaz, pois remove ruídos sem borrar tanto a imagem.





c) Qual foi mais eficaz para destacar as bordas?

O filtro Sobel, porque ele detecta variações de intensidade e evidencia os contornos.




d) Quais situações podem exigir o uso de cada filtro em um projeto real?

Filtro de Média: usado para suavização simples.
Filtro de Mediana: usado para remover ruídos em fotos e câmeras.
Filtro Sobel: usado em detecção de bordas e reconhecimento de objetos.
